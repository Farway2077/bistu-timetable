# ADR-0001：采用本机 WebView 登录和页面识别

## Status

Accepted

## Context

应用需要从北京信息科技大学教务系统自动识别学期课表。系统由学校统一认证保护，账号密码属于高敏感数据；同时，学校可能改变课表页面 DOM 或接口。首版由单人本地应用承担，不适合维护托管凭据的抓取服务器。

## Decision

使用 Android WebView 打开学校统一认证和教务系统页面，由用户直接在学校页面输入凭据。登录成功后，应用在设备本地注入只读提取脚本，读取当前课表页可见结构，再交给纯 Kotlin 解析器。应用不读取 Cookie 值、不保存密码、不把页面或课程上传到服务器。解析结果经用户确认后使用 Room 事务写入本地数据库。

## Consequences

### Positive

- 凭据直接提交给学校域名，不经过自建服务。
- 复用学校登录、验证码和可能的多因素认证流程。
- 已导入课表可完全离线查看。
- 解析器可用脱敏样本独立测试和升级。

### Negative

- 学校页面结构变化可能使自动识别失效。
- 用户首次导入仍需在 WebView 中完成登录和进入课表页。
- WebView 会话行为受系统 WebView 版本影响。

### Neutral

- 学校已有官方移动端服务，本应用定位为更专注的周课表查看器，而不是替代全部教务功能。

## Alternatives Considered

**服务器代登录**：能够集中修复解析器，但会扩大账号、会话和课程数据的暴露面，并引入持续运维，拒绝。

**调用未公开接口**：可能更稳定高效，但当前没有学校公开 API 契约；直接依赖内部接口存在变更和合规风险，暂不采用。

**只支持文件或截图导入**：安全简单，但不满足自动识别要求，仅保留为后续兜底。
