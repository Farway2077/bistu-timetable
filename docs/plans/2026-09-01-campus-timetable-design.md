# 北信科每周课表设计

## 目标与范围

面向北京信息科技大学学生制作一款原生 Android 课表应用。用户第一次导入时在应用内打开学校统一认证页面，自行完成登录；应用只读取登录后展示的课表内容并在设备本地保存，不保存账号、密码或验证码，也不把课程信息上传到第三方服务器。核心能力包括：按教学周查看周一至周日的课程、切换周次、定位本周、查看课程详情、刷新学期课表，以及在自动识别失败时给出可理解的诊断和手动维护入口。

首版不做云同步、社交、作业管理、桌面小组件或后台代登录。这样可以把权限和账号风险控制在最低，同时先保证“看得清、导得进、离线可用”三件事。

## 方案比较

| 方案 | 优点 | 代价与风险 | 结论 |
|---|---|---|---|
| App 内统一认证 + 本机页面识别 | 无需向第三方服务器提交密码；适配学校现有登录；可一键更新 | 学校改版后解析规则可能需要更新 | 采用 |
| 自建服务器代登录并抓取 | 可集中更新解析器 | 需要托管账号会话，隐私与运维风险高 | 拒绝 |
| 仅导入 Excel、截图或手工录入 | 实现稳定、权限少 | 不满足自动识别导入的核心诉求 | 仅作兜底 |

## 体验设计

主界面采用“课表纸页”方向：暖灰底色、深墨色标题、不同课程使用低饱和但区分明显的色块。顶部显示学期、当前教学周和日期范围；左右切换周次，点击“本周”快速返回。主体按星期列、节次行布局，课程卡片跨越实际节次数，卡面优先显示课程名、教室和教师。空白区域保持安静，不堆叠 HUD。

课表使用学校 2026 年 9 月 6 日起执行的 14 节作息时间。左侧节次栏在编号下显示每节课的起止时间；顶部周信息区域支持向左滑到下一周、向右滑到上一周，同时保留按钮操作，避免与横向浏览七个星期列冲突。

首次进入显示简洁的空状态和“从教务系统导入”主按钮。导入页顶部说明隐私边界，中间为学校登录网页；登录后应用检测到课表页面并自动尝试识别。成功时展示课程数、有效周范围和冲突提示，用户确认后原子替换当前学期数据。失败时保留网页，不要求重新登录，并提供“重新识别”“复制诊断信息”和“手动添加课程”。

## 系统结构

```text
Compose UI
  ├─ 周课表 / 课程详情 / 手动编辑
  └─ 教务导入 WebView
          │ 页面文本与结构快照（仅本机）
          ▼
ImportCoordinator
  ├─ BistuPageExtractor（JavaScript 页面提取）
  ├─ TimetableTextParser（课程、星期、节次、周次解析）
  └─ ImportValidator（去重、冲突、范围校验）
          │
          ▼
ScheduleRepository ── Room ── 本机 SQLite
```

应用采用单 Activity、Jetpack Compose、Navigation Compose、ViewModel、Room 和 Kotlin 协程。网络仅由 WebView 访问学校域名；解析器是纯 Kotlin 模块，可用真实脱敏样本做单元测试。数据库保存学期、课程和上课安排；周课表查询只展开当前周有效且奇偶周匹配的安排。

## 数据流与失败处理

1. 用户打开导入页，WebView 只允许 `https://jwxt.bistu.edu.cn`、统一认证域名 `https://wxjw.bistu.edu.cn` 及其跳转。
2. 用户自行输入凭据。应用不监听输入框，不写入日志，不启用密码自动保存。
3. 页面加载完成后，提取脚本递归读取同源 frame 中可见文本、表格和课程块，不读取 Cookie。
4. 解析器识别课程名、教师、地点、星期、节次和周次；校验器拒绝完全空白或明显不完整的结果。
5. 用户确认后，Room 事务替换当前学期数据。WebView 会话只由系统 WebView 管理。

若统一认证不可达，提示检查校园网/VPN；若登录成功但未到课表页，引导用户在网页中进入“我的课表”；若只解析出部分字段，保留可用课程并明确列出缺失项；若学校页面结构变化，输出不含账号和 Cookie 的解析版本、页面标题、URL 路径和节点计数，便于更新适配器。

### 当前七列课表适配

学校当前“我的课表”使用 React 七列网格，星期和节次主要由课程卡片所在列及位置表达，不能只依赖卡片可见文字。导入时优先在已登录的学校页面内调用其同源学生学期课表接口，读取课程名、星期、起止节次和周次；若接口暂时不可用，再按七列网格的星期标题、节次背景格和课程卡片位置提取。接口请求沿用系统 WebView 已建立的学校会话，但应用不读取或保存 Cookie 文本。

识别时以网页当前可见的学期选择器为准，不沿用接口返回的默认学期。若页面组件没有暴露选择值，则用当前七列网格中的课程与各学期接口结果做匹配；每次手动识别都重新生成结果并允许覆盖上一次预览。教室既读取结构化字段和“地点/教室”标签，也识别 `XXD-407` 一类独立教室代码。

结构化课程名始终优先于详情字段标题，“学生组”“课程信息”“上课信息”等标签不得作为课程名。缺少星期、节次或周次的记录不进入导入预览，并返回可操作的提示，避免把当前周的一部分课程误当成完整学期课表。

## 非功能要求

- 隐私：不保存密码、验证码、Cookie 文本或完整网页源码；课程数据仅存本机。
- 安全：禁止明文 HTTP；外部未知域名交给系统浏览器且默认不继续；发布版关闭 WebView 调试。
- 性能：常见 100 条以内安排的周过滤低于 50 ms；首次界面在普通设备上 1 秒内可交互。
- 可靠性：导入使用数据库事务，解析失败不覆盖已有课表；离线仍可查看已导入内容。
- 兼容性：Android 8.0（API 26）及以上，竖屏优先，适配小屏和深色模式。
- 可维护性：导入规则、领域模型和 UI 分层；解析规则必须有脱敏样本测试。

## 验收标准

- 首次启动能进入空状态并打开学校教务登录页。
- 示例课表可识别课程名、星期、节次、地点、教师及单双周/周范围。
- 周次切换正确隐藏不在该周的课程，重叠课程不会静默覆盖。
- 进程重启和离线状态下仍能查看已保存课表。
- 错误登录、非课表页、空课表和页面改版均不会清空原数据。
- 单元测试、Android Lint 和 Debug APK 构建通过；关键界面有模拟器或 Compose 预览验证。
