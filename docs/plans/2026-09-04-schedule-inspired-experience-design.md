# 纸间课表主界面体验升级设计

## 目标与边界

参考社区项目 Schedule 中成熟的课程浏览体验，把纸间课表从单一周网格升级为更适合每天打开查看的主界面。此次只调整 Compose 展示层和可独立测试的时间摘要逻辑，不修改 BISTU 教务接口、WebView 提取脚本、解析器、Room 表结构或导入确认流程。

参考项目采用传统 Android View 架构，纸间课表继续保留现有 Compose + ViewModel + Room 分层。本次只吸收“周视图与今日视图并存、顶部突出下一节课、低饱和课程配色、课程详情易读”等产品思路，不直接复制参考项目代码。

## 体验方案

主界面顶部显示当前日期、星期、学期和正在浏览的教学周，并用一张紧凑状态卡说明“正在上课”“距下节课”“今日已结束”或“今天没有课”。状态只在应用前台按分钟刷新，不增加后台服务和权限。

顶部下方提供“本周 / 今日”双视图切换：

- 本周视图保留 1–14 节完整课表，七天自适应屏幕宽度，无需横向滚动；当前日期列有轻量底色，点课程打开详情。
- 今日视图按上课时间纵向排列课程，显示节次、钟点、教室、教师和当前状态；没有课程时提供明确空状态，并允许返回本周视图。

课程颜色使用固定、稳定的低饱和色组，并分别适配浅色和深色主题。课程卡片优先展示课程名，其次展示教室；完整教师、周次、钟点和冲突信息放入详情弹窗，避免小尺寸周网格过载。

## 状态与数据流

`TimetableViewModel` 继续只负责学期、课程和所选周。新增的 `TimetableSummary` 纯 Kotlin 逻辑根据学期开始日期、当前日期时间和课程列表计算：当前教学周、今日课程、正在进行的课程、下一节课程及分钟数。Compose 层消费这一摘要并决定文案和状态样式。

时间摘要不写数据库，也不影响导入结果。日期不在学期范围内时，今日视图为空；浏览历史或未来教学周时，周视图仍按所选周展示，顶部今日状态保持指向现实中的今天。

## 失败、边界与无障碍

- 节次没有对应作息时间时，不参与“下一节课”计算，但仍可在合法网格范围内展示。
- 同一时间的重叠课程沿用现有冲突检测，并在周卡、今日卡和详情中提示。
- 课程卡片提供包含课程名、节次和教室的语义描述；视图切换和周导航保留明确文本标签。
- 加载、未导入、今天无课、本周无课和学期范围外均有独立状态，不以空白网格代替反馈。

## 验收标准

- 可在本周与今日视图之间切换，旋转或重组时当前模式可恢复。
- 顶部状态正确区分无课、未开始、上课中和已结束。
- 周视图在常见竖屏宽度内同时显示周一至周日，仍可纵向滚动查看 14 节。
- 今日视图按节次排序，课程详情与冲突提示可用。
- 深浅色主题下文字与课程卡片均保持足够对比度。
- `importer/`、导入 ViewModel、教务 URL 和数据库 schema 无变更。
- 单元测试、Android Lint 和 Debug APK 构建通过。
