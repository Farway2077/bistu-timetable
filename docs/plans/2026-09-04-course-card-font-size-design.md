# 课程卡片字号设置设计

## 目标

允许用户调整课表课程卡片的文字大小，同时不挤占已经压缩过的顶部空间。字号设置只影响本周网格卡片和今日课程卡片，不改变日期、节次轴、状态卡、详情弹窗或系统字体设置。

## 交互

把标题区原来的“首周 M/d”入口改为“设置”，与“同步”并列。设置弹窗内保留首周日期入口，并新增“小、标准、大、特大”四档课程卡片字号。选择字号后卡片立即更新，标准档保持当前视觉大小；重新打开应用仍使用上次选择。

四档预设比连续滑杆更适合七列窄网格：结果稳定、易于回退，也可以为每档给出准确无障碍名称。大字号可能减少同一卡片可显示的文字量，课程名和教室继续使用省略规则，避免文字溢出卡片。

## 技术与边界

新增一个小型 `TimetableDisplayPreferences`，用应用私有 `SharedPreferences` 保存枚举名称，不增加 Room 表或网络依赖。未知或旧值自动回退到“标准”。Compose 层将档位倍率传给周卡和今日卡；详情弹窗保持系统排版。

教务接口、WebView、解析器、课程数据和首周日期数据库更新逻辑不变。验收包括存储回退测试、全部 JVM 测试、Android Lint 和 Debug APK 构建。
