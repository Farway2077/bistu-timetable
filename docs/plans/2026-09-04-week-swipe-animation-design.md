# 周切换跟手动画设计

## 目标

周课表改为真实的横向分页手势。拖动过程中，当前周跟随手指位移并同步露出相邻周；松手后根据位移和速度吸附到目标周，未达到切换条件时平滑回弹。上一周、下一周和“返回本周”按钮也驱动同一个分页器完成滚动。

## 交互与布局

顶部日期、今日状态和“本周 / 今日”切换保持固定，周导航、日期行与课表网格组成一个完整分页。分页采用 Compose `HorizontalPager` 的原生拖拽、速度追踪和吸附行为，因此不再等待松手后才播放预设动画，也不再自行维护固定像素阈值。

每一页根据自己的教学周计算日期、课程和冲突状态，并预加载相邻一页，拖动时不会先显示旧数据再跳变。页内继续使用独立的纵向滚动状态；Pager 负责协调横向手势，斜向或纵向滚动不会被简单累计成换周操作。

`selectedWeek` 仍是应用层的周状态。分页完全吸附后把当前页同步给 ViewModel；按钮或首周日期变化引起的外部周状态更新，则调用分页器动画滚到对应页，避免分页位置和标题状态分离。

## 边界与验收

- 第 1 周和最后一周保留系统边界反馈，不会越出学期范围。
- 慢拖、快速轻扫、拖动后放弃都具有连续位移与自然吸附。
- 空周、课程冲突、字号设置和首周日期设置在每个分页中正确更新。
- 今日视图不参与横向周分页。
- 单元测试验证周数和分页索引的双向映射及边界钳制；全部测试、Lint 与 APK 构建通过。
