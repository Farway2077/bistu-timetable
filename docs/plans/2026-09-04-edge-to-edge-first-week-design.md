# 课表顶部与首周日期设置设计

## 目标与现状

真机截图显示状态栏仍使用固定浅色背景，而 Compose 内容已经是深色主题；课表页面同时预留状态栏安全区，因此顶部出现浅色边缘，主体也显得偏下。本次让应用背景绘制到系统栏下方，并只保留一份安全区，同时压缩标题、状态卡和视图切换间距。

## 交互方案

标题区保留日期、教学周、学期和同步入口，新增紧凑的“首周 M/d”按钮。点击后打开 Material 3 日期选择器，文案明确要求选择“第 1 周周一”。只有选择星期一时才可保存，避免周一至周日列与日期错位。

保存后直接更新现有 `semesters.start_date`，不增加 Room 字段或迁移，不改 WebView、页面提取、解析和教务接口。ViewModel 清除手动选周，让当前教学周依据新日期重新计算。顶部按钮和周范围随数据库 Flow 自动刷新。

## 边界与验收

- 深浅主题下状态栏背景与应用连续，图标保持可读。
- 页面不再重复消费顶部系统栏内边距，课表网格获得更多垂直空间。
- 首周日期只接受星期一；取消不写入，保存后重启仍保留。
- 更新不存在的学期时明确失败，不产生半更新数据。
- 教务 URL、导入提取器、解析器、课程和上课安排不变。
- 单元测试、Android Lint 与 Debug APK 构建通过。
