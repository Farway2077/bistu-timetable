# 学习助手
用户授权按推荐直接扩展实用功能。优先实现离线待办、课程搜索和空闲节次；云同步和桌面小组件留待专门迭代。
- 待办支持新增、编辑、完成/恢复与确认删除，记录类型、课程名、截止时间和备注。
- 独立 Room 表不引用教务课程 ID，同步、撤销和切换学期保留待办；数据库版本 2 无损升级为 3。
- 按指定日期查看和搜索实际课程，另提供全学期搜索，按课程名、老师和教室匹配，复用临时停课与跨周调课逻辑。
- 空闲节次表示个人课表在 1–14 节的连续空档，不代表教室可用；无课表或学期外不推断空闲。
- 校验标题、日期时间与内容长度；保存失败保留输入，写入中阻止重复操作。
- 验证领域边界、调课/停课、重叠课程、搜索、截止状态及迁移；运行单元测试、Lint 和 APK 构建。有设备再做 Android 验证。
